# CashIOL

Tablet-first self-service kiosk interface for digital cash-in, digital cash-out and Philippine mobile loading.

## GitHub Pages

This frontend is static and can open directly on GitHub Pages. No Node.js server is required to display the kiosk UI.

Enable **Settings → Pages → Deploy from a branch → main → /(root)**.

Expected URL: `https://justine976.github.io/CashIOL/`

The payment QR in this version is a placeholder. No real money moves until approved payment, payout and loading providers are connected through a secure backend. Never put provider secrets, OTPs or wallet PINs in the frontend.
